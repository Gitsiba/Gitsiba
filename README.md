## How I approach a strong analysis

1. Define the biological question, inputs, and expected outputs.
2. Apply appropriate quality control and document filtering decisions.
3. Use traceable, parameterized workflows and record software versions.
4. Validate outputs with quality metrics and independent checks.
5. Produce interpretable plots and concise biological conclusions.
6. Document limitations, reproducibility steps, and responsible data handling.
